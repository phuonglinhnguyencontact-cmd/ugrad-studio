# UGRAD Studio

Pastel static dashboard for planning a Global UGRAD application.

- Theme: pastel pink #FFB6C1, baby blue #B0E0E6, lime #DDE874
- Font: Google Sans Flex (requires internet)
- Entry point: index.html

## GitHub Pages
Enable Pages in **Settings → Pages → Deploy from a branch → main → /(root)**.

## Privacy and data
- This public edition does not embed the applicant's GPA, IELTS score, school, or name.
- Tasks, notes, English logs and settings are stored in localStorage in the browser used; they do not sync between devices.
- Use Export Backup / Import Backup for portability. Do not enter sensitive personal information.

All application schedule dates are internal planning targets. Verify current Vietnam-specific deadlines and requirements with official program sources.
